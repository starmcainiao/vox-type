# compiler/ · 预铸与校验（冻结区）

## ① 职责 / 不负责什么

**职责**：把「话术 + 剧本」编译成「资产包」，并在编译期拦住一切不合规。
- **预铸流水线**：话术 → 逐句合成（多语速档 × 多变体）→ 质检 → 入库/打包
- **四属性校验器**：无非法吸收态 / 所有 key 可达且已预铸 / 不夹带未审核文本 / 有界（循环与追问上限）
- **差量重铸**：文本/音色/语速/模型版本任一变化 → 仅重铸受影响资产（靠文本指纹）
- **产物**：资产包 + 校验报告 + 预铸账（条数/时长/字节/失败原因）

**不负责**：不做命中判定与播放（`runtime/`）、不实现 TTS（`adapters/`）、不定义协议（`core/`）。

## ② 输入 / 输出契约

- 输入：`packs/<业务>/`（话术 + 剧本 + 参数）+ `rules/` 的规则集 + `adapters/` 的 TTS 引擎。
- 输出：`assets/` 格式的资产包 + **校验报告（JSON）** + 预铸账。
- 产物必须自描述：包内含协议版本、规则集版本、音色与模型版本、逐条资产指纹。

## ③ 验收条件

1. **不合规必拦**：`rules/` 的反例剧本全部被拒，且报告指出违反的规则编号；
2. **可复现**：同一输入两次预铸，资产指纹集合一致（幂等）；
3. **陈旧检测**：改一句话术 → 重铸后只有该条指纹变化，其余资产复用（差量生效）；
4. **质检不过不入包**：削波/头尾静音异常/响度越带的字模必须被拒绝并计入报告（不得静默跳过）；
5. **失败不静默**：任何合成失败必须出现在报告的 `failed[]` 中并带原因。

## ④ 本层数据收集

预铸账：条数 / 总时长 / 总字节 / 失败条数与原因 / 质检分布 / 每类规则的触发次数（回传 `rules/`）。

## ⑤ 依赖边界

- 允许依赖：`core/`、`rules/`、`adapters/`（仅经接口）。
- 禁止：不得依赖 `runtime/`、`eval/`；不得把业务逻辑写进流水线。

## ⑥ 变更纪律

改校验口径 = 契约变更 → 同步更新 `docs/`、`rules/`（若涉及规则定义）、以及所有 `packs/` 的合规回归。

## ⑦ 冻结状态

**[冻] 冻结区**。流水线内部实现可换（并行/串行、不同 TTS），但**产物格式与校验语义不变**。

## ⑧ 实现变更记录（T18 · 2026-09-22）：源的 ttl / invalid_at 与预铸折算

**核心红线**：过期资产不得被播出。本层负责在**编译期**把「相对时长」折算成
「绝对时刻」，让资产层只在运行期看一个字段。

### 字段只增，旧源行为完全不变

| 源字段（`phrases.json` 单条） | 校验 | 缺省时 |
|---|---|---|
| `ttl` | 正整数秒；`0` / 负数 / `"3600"` / `1.5` / `true` 全部 → `SourceError` | 不折算，条目永不过期 |
| `invalid_at` | 可解析 ISO 8601 字符串，否则 → `SourceError`（消息含实际值） | 无失效时刻 |

两者在源里**互斥**：同时给 → `SourceError`（消息含 key 与两个字段名及实际值）。
不猜哪个优先——两个口径（相对 vs 绝对）同时存在时，谁赢都是一种静默选择。

白名单 `PHRASE_ALLOWED_FIELDS` 只增不减（`+ttl` / `+invalid_at`）；`duplex` 写错
一个字母仍报未知字段——typo 必须响，不许静默丢弃。

### 折算规则（裁定）

`ttl` = 相对秒数，从**预铸时刻**起算；`invalid_at` = 绝对失效时刻。manifest 存
`invalid_at`（绝对，判定唯一依据）**+ 可选保留 `ttl` 原值供审计**；`lookup` 只按
`invalid_at` 判。

- 折算基准 = `manifest.created_at`（同一份 `_iso_now()` 的值），因此
  `invalid_at == created_at + ttl` 对验收方可**独立复算**（容差 ≤ 2 秒）。
- 折算只发生在**枚举待铸条目**时一次，运行期不做二次折算（避免两处各算一份）。

### 迁移说明

- **旧源 / 旧包：零改动即可继续用**。不带这两个字段的源铸出的 manifest 条目
  **不含**失效键，与既有产物逐字节一致（见
  `compiler/tests/test_ttl.py::TestPrebakeTtl::test_legacy_source_manifest_has_no_expiry_fields`）。
- **新源要加失效声明**：在 `phrases.json` 的单条话术上加 `ttl`（推荐——业务侧给秒数
  即可，绝对时刻由预铸时刻决定）或 `invalid_at`，然后重新 `vox pack build`。
  无需迁移脚本。
- **既有 fail-closed 语义不变**：带失效字段的源同样遵守「不干净 → 不写 manifest」
  （见 `test_partial_failure_still_fail_closed`）。

### 判定与验收

- `compiler/tests/test_ttl.py`（17 条）：正例（`invalid_at` 未来 → 铸包成功、manifest
  落字段）、**互斥**、7 类非法值（各自报错且消息含实际值）、`ttl=3600` 折算复算
  （容差 ≤ 2 秒）、`lookup(now=)` 在失效前后行为相反、旧源零变化、时间注入可重放。
