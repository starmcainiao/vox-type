# 任务卡模板（给 OpenCode 执行模型用）

> 用法：复制本模板 → `docs/tasks/NN-<层>-<做什么>.md` → 交 `blackiron-opencode-writer` 派发 → 我验收。
> 写卡原则：**OpenCode 只能看到这张卡 + 仓库文件**，所以卡必须自包含（路径、约束、验收全写清）。
> **含用户录音/真实会话/内部地址/token 的任务卡一律不得派发给免费档模型**（免费档有数据留存风险）；走有密钥的付费模型前也要确认卡内数据分级为公开。

---

## 卡号 / 标题
`T{NN} · {层}：{一句话目标}`

## 背景（只写必需）
为什么做这件事；依赖哪一层已交付的产物（写路径）。

## 目标（可验收的产物）
- 产物 1：`path/to/file`（做什么用）
- 产物 2：`path/to/test`（对应测试）

## 允许修改的文件（白名单）
```
允许新增：core/*.py, core/tests/*.py
允许修改：无
禁止触碰：其他一切文件（尤其不得改 README.md / AGENTS.md / docs/）
```

## 禁止事项
- 不得新增第三方依赖（除非卡里明确列出）
- 不得改动本卡白名单以外的任何文件
- 不得"顺手优化"、"顺手重构"、不得改动与本卡无关的格式

## 验收标准（逐条可判定，我会逐条核对）
1. …
2. …（含至少一条**负例**：非法输入必须被拒）
3. 测试全绿：`python3 -m unittest discover -s {层}/tests -v`

## 反空转条款（每张卡必带，T01 教训）
- **测试必须调用产品 API**：不得在测试文件内定义/复制被验逻辑（违者整卡退回）；
- 测试名必须与实际调用路径一致（禁止名为 `*_in_unit` 却只测独立辅助函数）；
- **正例与负例都要有**，且负例断言**错误消息包含具体非法值**；
- 不得为通过测试而放宽校验；既有校验强度只增不减（验收方会比对异常抛出点数量）。

## 回滚方式
删除本卡新增的文件即可（不触碰既有文件 → 回滚 = `git clean`）。

## 执行方式

**首选**（2026-09-17 起）：交 ZCode 子智能体 **`vox-card-executor`**（跑在 ZCode 的「商汤」provider 上，`sensenova-6.8-flash-lite`，自带 Write/Edit 直接落地）。
定义：`~/.zcode/agents/vox-card-executor.md`；**新建/改动 agent 定义后需新开会话才注册**。

**回落**（`vox-card-executor` 不可用时）：
```
cd （仓库根）
opencode run -m sense-nova/sensenova-6.8-flash-lite "$(cat docs/tasks/NN-xxx.md)" --dir （仓库根）
```
免费档（`opencode/*-free`）仅在主模型不可用时再回落，并在报告里点名。

**含用户数据/密钥/内网地址的卡两条路都不许派** —— 一律本地模型执行。
