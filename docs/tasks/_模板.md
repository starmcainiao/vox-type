# 任务卡模板（给 OpenCode 免费模型执行用）

> 用法：复制本模板 → `docs/tasks/NN-<层>-<做什么>.md` → 交 `blackiron-opencode-writer` 派发 → 我验收。
> 写卡原则：**OpenCode 只能看到这张卡 + 仓库文件**，所以卡必须自包含（路径、约束、验收全写清）。
> **含用户录音/真实会话/内部地址/token 的任务卡一律不得派发**（免费档有数据留存风险）。

---

## 卡号 / 标题
`T{NN} · {层}：{一句话目标}`

## 背景（只写必需）
为什么做这件事；依赖哪一层已交付的产物（写路径）。

## 目标（可验收的产物）
- 产物 1：`path/to/file`（做什么用）
- 产物 2：`path/to/test`（对应测试）

## 允许修改的文件（白名单）
```
允许新增：core/*.py, core/tests/*.py
允许修改：无
禁止触碰：其他一切文件（尤其不得改 README.md / AGENTS.md / docs/）
```

## 禁止事项
- 不得新增第三方依赖（除非卡里明确列出）
- 不得改动本卡白名单以外的任何文件
- 不得"顺手优化"、"顺手重构"、不得改动与本卡无关的格式

## 验收标准（逐条可判定，我会逐条核对）
1. …
2. …（含至少一条**负例**：非法输入必须被拒）
3. 测试全绿：`python3 -m unittest discover -s {层}/tests -v`

## 回滚方式
删除本卡新增的文件即可（不触碰既有文件 → 回滚 = `git clean`）。

## 执行方式
```
cd /Volumes/macos/newProject/vox-type
opencode run -m opencode/mimo-v2.5-free "$(cat docs/tasks/NN-xxx.md)"
```
（模型可换：`nemotron-3.5-lightning-free` 更快，`nemotron-3-ultra-free` 更稳）
