# T85 · examples：自证脚本在长步骤期间必须给出等待提示（不再像卡死）

## 背景（只写必需）

实测（2026-10-12，见 `T84` 批次索引）：`sh examples/selftest.sh` 全程 **94 秒**，
其中 2d 那一步是**真实模型铸整包**，而 `run_step()` 用的是

```sh
out="$("$@" 2>&1)"
```

——**命令的全部输出被捕获进变量**，终端上什么都不显示。
`docs/22 §2` 又教新人「看 stderr 的 `[prebake] N/?` 进度行确认没卡死」，
于是新人照着文档做，会面对一个**长达一分多钟毫无输出的黑屏**，极容易 `Ctrl+C`。

**本卡只解决"看起来像卡死"，不引入并发/管道改造**（那属于另一张卡）。

## 具体改法（**逐字照做，不要自由发挥**）

在 `run_step()` 里，**执行命令之前**打印一行等待提示，**执行之后**打印耗时。目标是改完这一段
（原文见 `examples/selftest.sh` 的 `run_step()`）：

```sh
run_step() {
    step="$1"; want_rc="$2"; shift 2
    out="$("$@" 2>&1)"; rc=$?
```

改成（**只加两处打印，其余一行不动**）：

```sh
run_step() {
    step="$1"; want_rc="$2"; shift 2
    printf '  … 正在跑 %s（引擎类步骤可能要几十秒到几分钟，中途没有输出属正常，不要 Ctrl+C）\n' "$step"
    _t0="$(date +%s)"
    out="$("$@" 2>&1)"; rc=$?
    _t1="$(date +%s)"
    printf '  … %s 结束（耗时 %s 秒）\n' "$step" "$((_t1 - _t0))"
```

**约束**：`out=` 那一行必须保持原样（判定仍走它）；`rc=$?` 必须**紧跟**该行（不得插进任何命令之间，
否则 `$?` 会被覆盖）。

## 验收标准（逐条可判定，验收方逐条核对）

1. `sh -n examples/selftest.sh` 语法通过（无输出、rc=0）；
2. 实跑 `sh examples/selftest.sh`，终端输出里**必须同时出现**：
   - 至少一行 `… 正在跑 `；
   - 至少一行 `… 结束（耗时 `；
   - 结尾仍是 `SELFTEST: PASS`（或环境缺件时为 `PARTIAL`），**退出码与改动前一致**；
3. **负例（判定未被削弱）**：把 `run_step` 的期望 rc 临时改成一个必然不成立的值（如把某步的
   `0` 改成 `9`），实跑必须出现对应的 `✗` 与末行 `SELFTEST: FAIL`，退出码 `4`；**改回后必须恢复 PASS**。
   （这条是"注入必红"自证，验收方会亲跑；不接受"我看过代码觉得没问题"。）
4. 计时值必须是**真实耗时**，不是常量：连跑两次，两次的秒数允许相同但**不得恒为 0**
   （若某步确实 <1 秒，允许为 0——此时用另一条长步骤（2d 铸包）核对非 0）。
