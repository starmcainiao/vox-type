# T43 · 前置包价值对比（一眼明白版：可复跑 harness + 对比图）

> 层：`labs/`（实验区，产物自带口径与原始数据）+ `docs/media/`（呈现素材）
> 由来：2026-09-24 会话——用户要求「做一个业务验证对比先来，让人一看就明白前置包解决什么问题」
> 依赖：无（不碰冻结区）；执行走 dynamic workflow。

## 一、目标

把「前置包解决了什么问题」从主张变成**本仓自测、可复跑、一眼明白**的对比：
同一批话术、同一台机器，对照三条路径的首音与业务属性——

| 臂 | 实现 | 说明 |
|---|---|---|
| **快路（前置包）** | `vox run` 命中即播 | 磁盘读，零 TTS 调用 |
| **慢路（现场合成）** | `adapters.tts_omlx`（oMLX `Qwen3-TTS-12Hz-0.6B-Base-bf16`）全链路：合成 → 16k 降采样归一 | 采样型小模型，**不用 `say`** |
| （背景参照，只引不跑） | 云端链 / 端到端 | 引用 `labs/cloud-bench/report.json`、`labs/e2e-vs-cascade/` 落盘值，**标注口径不同、不直接相减** |

## 二、产物与白名单

| 文件 | 内容 |
|---|---|
| `labs/frontpack-value/run_compare.py` | 可复跑 harness（零第三方依赖）：固定语料 N=10 句（heat_kefu，含 `examples/plan.json` 的 4 个 key），两臂实测，落盘 |
| `labs/frontpack-value/raw/*.jsonl` | 每句每臂的原始记录（不可手改） |
| `labs/frontpack-value/report.json` | **数字唯一来源**：两臂的 N / P50 / min / max、实时倍率、机器与模型加载状态、语料清单 |
| `labs/frontpack-value/README.md` | 口径与复跑命令；如实列出局限（本机、单账号、无网络） |
| `docs/media/value-compare.svg` | 一眼明白图：对数刻度横条（快路 vs 慢路），标注数值与单位；合法 XML、无外链、被 T44 引用 |

## 三、禁止事项

1. **不用 macOS `say`**（实际场景非 mac）；不引云端 API（背景数字只引用既有落盘值）；
2. 不改内核/冻结区；不新增第三方依赖；
3. **不夸大**：不得写"快 4000 倍"这类裸倍数——必须写成「同机同句首音 0.7 ms vs 2.9 s（约 4000×），口径见 report.json」并给区间；
4. 场景必须真实可复跑（固定语料、固定步骤），不许手抄数字进文档。

## 四、验收标准

1. **可复跑**：`python3 labs/frontpack-value/run_compare.py` 在端点在线时 rc=0，产物齐全；
2. **数字可溯源**：report.json 字段齐（两臂 N/P50/min/max、倍率、语料 keys、机器状态）；README 与 SVG 里的数字与它一致（验收员逐值对照）——
   **以最近一次 report.json 为准**：多次复跑数字会漂（实测 fast p50 0.710/0.715 ms、slow p50 2088.5/2336.0 ms、rtf 0.967/0.941），
   README 必须同步到**最新一次**并保留区间/波动说明（2026-09-24 收尾批：首版 README 停在旧一次跑，被验收员逐值抓出）；
3. **图合规**：SVG 合法 XML、无 `<image>`/外链、对数刻度、含单位与口径提示；
4. **诚实口径**：两臂同机同句含完整后处理可比；云端数据只作参照并标注；模型加载状态如实写；
5. 结构预算 `--no-write` rc=0；冻结区零改动。

## 五、回滚方式

`git checkout -- .`（全新增目录）；删除：`git clean -fd labs/frontpack-value/ docs/media/value-compare.svg`。
