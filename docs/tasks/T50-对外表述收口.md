**① `README.md:24` 英文一行**
- 现在：`plays them in ~0.2 ms when the upstream model decides to speak them`

- 理由：外部读者只读英文那句；0.2 ms 是 `say` 旧口径，与同屏表格自相矛盾。
  **必须同时**在同屏加一句交叉说明：链路对拍口径（0.232 ms，`docs/09`）是**另一台机器、另一口径**。

**② `README.md:35` 表格与 ① 的一致性**
- 表格数字（0.715 / 2336.0 / 3,267×）**保持不动**（有 `labs/frontpack-value/report.json` 背书）。
