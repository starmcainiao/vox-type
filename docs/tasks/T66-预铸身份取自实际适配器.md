# T66 · 预铸产物的引擎身份取自实际适配器（冻结区·待开批）

> 来源：T1 决策层「业务产品票」缺口 #2 + 本人复核
> **本卡只起草，执行与否由维护者拍板。**

## 一、问题（已复核，确定性复现）

`compiler/prebake.py:352-353` 把产物的引擎身份从**源包**取，而不是从**实际干活的适配器**取：

```python
voice=source.voice,
model_version=source.model_version,
```

而 `packs/heat_kefu/pack.json` 里写的是：

```json
{"voice": "Tingting", "model_version": "macos-say"}
```

——这是 **macOS say 的身份**。所以用 oMLX 合成出来的音频，打包后会被盖上 macOS say 的戳。

实测后果：README Quick Start 第 2 条命令直接 fail-closed：

```
$ sh bin/vox run examples/plan.json --pack /tmp/vox-demo/hk3 --adapter adapters.tts_omlx:OmlxTts
run: 已按 fail-closed 中止（reason=engine_mismatch）    rc=5
```

因为 `runtime/executor.py:426-427` 的指纹一致性检查发现 `pack.voice != adapter.voice`。
**那道护栏是对的**，错的是上游给它喂了假身份。

更值得注意的是：**同一个文件里已经有正确写法**，只是没用：

```python
# prebake.py:259-260（增量复用分支）
and old_pack.voice == getattr(adapter, "voice", source.voice)
and old_pack.model_version == getattr(adapter, "model_version", source.model_version)
```

所以这是**同文件内的不一致**，不是设计选择。

## 二、为什么必须开冻结区

`compiler/` 是冻结区。`runtime/executor.py:426-427` 的那三行**不许动**（那是好的）。
`runtime/` 同为冻结区。

## 三、做什么

1. `prebake.py:352-353`（以及 `:121-123` 若同型）改成 `getattr(adapter, "voice", source.voice)` 形式，
   与 `:259-260` 对齐。**加 getattr 兜底**是为了让「不提供 adapter 的旧调用路径」不炸。
2. 身份不匹配时**必须报错**，不许静默取 source（那就是现状的病）。
   但也别反过来强制每个适配器都必须有 `voice`——`getattr` 兜底 + 缺失时**显式警告**即可。
3. 补测试：一个「用 omlx 铸包 → manifest 的 voice 必须等于 omlx 的 voice」用例。
   这条现在会失败——**它就是这条卡的回归证据**。
