## 目标（四项，逐项可验收）

1. **#15 门禁装牙齿**：`vox bench` 在 `reference_gate` **不通过**时 **exit 4（EXIT_QUALITY，`docs/08` 冻结退出码表）**；
   gate 通过 → exit 0；**报告内容不变**（只允许**加** gate 结论字段，数字仍如实上报——"数字如实"与"退出码反映结论"是两件事）。
2. **#16 结构预算台账 + 检查脚本**：新增 `tools/structure_budget/`（脚本 + 台账 + README）：
   - 扫各层 `.py` 的**可执行行数**（**排除注释与 docstring**，与既有口径一致：`adapters/AGENTS.md §⑨` 的 145–150 口径）；

   - 超限且未在该层 AGENTS.md 登记豁免 → **非 0 退出**并列出违规（文件、实际行数、阈值）；
   - 台账（当前各层文件行数快照）落盘到 `tools/structure_budget/`，可复现。

   **bench↔report 的指纹咬合耦合**（bench 写指纹 ↔ report 重算校验）的注释必须保留；
   去重后各调用点行为**逐位一致**（用既有测试 + 一次对拍证明）。
4. **#18 公开面补齐**：`cli.commands.bench.load_corpus` 可导入（走公开导出）；`core.metrics_spec.METRIC_FIELDS`
