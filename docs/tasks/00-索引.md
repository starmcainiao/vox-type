# 任务卡索引（vox-type）

> 工作方式：我拆卡 → `blackiron-opencode-writer` 派发给 OpenCode 免费模型 → 我验收（必要时调只读审查员）。
> 每张卡自包含（路径/白名单/禁止/验收/回滚），因为执行者只能看到卡本身。

## 卡状态说明

- **未开始** → 等依赖卡验收通过再派发（不允许跳序，避免返工）。
- **待派发** → 卡已写好，等派发给 OpenCode。
- **已派发 / 已回收** → 由写手回填事实（改了哪些文件、越界与否）。
- **验收通过 / 退回** → 由我回填（附证据或原因）；退回卡不允许"差不多过"。

## 派发纪律（写手的职责边界）

- 写手只做：三项拦截检查（数据分级 / 文件白名单 / 回滚基线）→ `opencode run`（免费模型）→ `git status` 核对越界 → **只回事实**。
- 写手**不做达标判定**；达标与否由我判定，必要时调 `blackiron-code-reviewer` / `blackiron-rule-auditor` / `blackiron-silent-failure-hunter` 做源码级审计。
- **敏感数据红线**：卡里出现用户录音、真实会话、内部地址/token → 一律拒绝派发。
