# T21e · labs：把自扫做实（注释漏扫 + 自我描述不实 + 我上一卡的过度工程）

## 背景（只写必需）

T21d 把文字陈述的自校验从"一段"扩到"整个目录"，方向对了，但**机制本身有三处必须理直的问题**——
我逐条实测过，不是推测：

### 问题 1：行内 `#` 注释根本没被扫到（卡的验收未达成）

实测（我做的）：

| 注入位置 | 结果 |
|---|---|
| `README.md` | 注入禁语 → **rc 3**（点名文件）✅ |
| `run_e2e.py` 的**文档串** | 注入禁语 → **rc 3** ✅ |
| `run_e2e.py` 的**行内 `#` 注释** | 注入禁语 → **rc 0** ❌ **漏扫** |

卡明确要求"扫 `source_map.json` + `README.md` + `tickets.source.json` 的注解文字 +
**`run_e2e.py` 的说明文字**"——**行内注释就是说明文字**，现在漏了。
而且文件里**现存 1 条注释含禁语**（`# 「没有任何一条规则的 when 依赖 overdue_days」这类**真话不在禁语表里**。`），
纳入扫描就会红——这说明漏扫不是理论问题。

### 问题 2：这个机制**自己打印了一句假陈述**

`_strip_docstrings` 的实际行为是：**只跳过 `"""` 定界符，不跳过里面的内容**（逐字符 `out.append(src[i])` 一直在跑）。
所以文档串内容其实还在被扫（问题 1 里"文档串能被抓到"正是因为这个 bug）。
但它的输出标签写着 **"已剥除文档串"**——**这是一句假的自我描述**。
一个专门用来抓假陈述的机制，自己的输出就是假的，这必须改掉。

### 问题 3：我上一卡的措辞导致了一处过度工程（该撤）

T21d 卡写了"不得在断言里硬编码这三组数字"，本意是**计数必须从 `trigger.json` 现算、不许写死**。
执行方把它理解成"断言正文里不许出现 `2`/`3`/`0` 字面量"，于是用 `chr()` 拼出 `_ZERO`、`_MIN0_WORD`，
**它自己报告"语义等价，但可读性下降"**。这是我的措辞问题，该撤。

## 目标（可验收的产物）

- 产物 1：`run_e2e.py` —— **自扫目标改为「文件全文 − 禁语表字面量区间」**：
  不再剥注释、不再剥文档串；`_strip_docstrings` **删掉或改成真正做对的事**（不得留一个与行为不符的名字）
- 产物 2：`run_e2e.py` —— 在新范围下会命中的地方**改写成不逐字复制禁语的描述性说法**
  （我实测有 2 处：一条 `#` 注释、一条断言消息里引用的"用得不多"）
- 产物 3：`run_e2e.py` —— 撤掉 `chr()` 拼数字的过度工程（见下"正确的做法"）
- 产物 4：`source_map.json` 与 `README.md` —— 统一「跨批待办」编号口径
- 产物 5：重跑产物 `summary.json` / `raw/turns.jsonl`

## 正确的做法（问题 3 的口径，别再过度解读）

- **必须**：计数值（几条规则依赖某字段）**从 `packs/demo-brief/trigger.json` 现算**，不得写死；
- **允许、且鼓励**：把算出来的值直接格式化进断言消息（`f"...{n} 条..."`）——
  它来自现算，不会过期；
- **不需要**：为了让源码里不出现数字字符而用 `chr()` / 拼接等手法。**可读性优先**。

## 禁止事项

- **不得删既有断言**（T21d 后是 145 条，只增不减）
- **不得放宽扫描强度**：禁语表可以继续作为"必须写下的被禁原话"的**唯一**例外区间，
  但**不得再用"剥掉某段"的方式缩小扫描范围**（那正是问题 1 的成因）
- 不得把被禁短语改成同义模糊说法来绕过（例如把"用得不多"换成"较少使用"仍属规避）——
  正确做法是**改成与实测一致的具体陈述**，或**用描述性文字指明"某类模糊表述"而不复制它**
- 不得改 `packs/`（本卡只改 labs）
- 不得联网；不得新增依赖；**不要 `git add` / `git commit`**；**不要做达标判定**
- **判退出码不要接管道**：用 `python3 labs/ticket-source/run_e2e.py >/tmp/e2e.log 2>&1; echo $?`
  （`... | tail; echo $?` 取到的是 `tail` 的退出码，会把崩溃藏起来——这是本项目踩过的坑）
